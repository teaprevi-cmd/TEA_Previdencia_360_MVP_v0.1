# Manual operacional de homologação
1. Trabalhar somente com dados sintéticos.
2. Executar testes automatizados.
3. Simular o workflow e verificar retornos à coleta.
4. Inspecionar trilha de auditoria.
5. Registrar defeitos e evidências.
6. Não conectar documentos, e-mail, Meu INSS, OCR externo ou modelos de IA antes de revisão de segurança, privacidade e contratos.
